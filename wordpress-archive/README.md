# sgtuff.org.sg WordPress archive (24 Oct 2026)

Snapshot of the old WordPress site (WPX) before shutdown. Not part of the live website build.

- `json/` — 234 posts, 13 pages, categories and tags, as returned by the WordPress REST API
- `media/` — 280 images and files referenced in posts and pages (filenames = upload year_month_name)
- `sgtuff-content-inventory.csv` — every item with date, old URL, word count and a suggested migration bucket (for committee sign-off)
